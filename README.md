# Trabajo-libre-06-Vuejs
# 🚀 Motion Tasks

Una aplicación moderna de gestión de tareas desarrollada con **Vue.js 3**.
Diseñada para ser interactiva, intuitiva y visualmente atractiva.

---

## ✨ Características

* ✅ Crear tareas con título y descripción
* 🎯 Marcar tareas como completadas
* 🗑 Eliminar tareas con animación
* 📖 Expandir y ocultar descripción
* 💫 Animaciones suaves con `<transition>` y `<transition-group>`
* 🎨 Diseño moderno con glassmorphism
* 🌊 Fondo animado dinámico
* ⚡ Reactividad en tiempo real

---

## 🛠 Tecnologías Utilizadas

* **Vue.js 3 (CDN)**
* HTML5
* CSS3 (Animaciones + Glassmorphism)
* JavaScript (ES6)

---

* 🗑 Salida con fade + slide
